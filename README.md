# JAOPCA: Ex Deorum

Adds [JAOPCA](https://www.curseforge.com/minecraft/mc-mods/jaopca) compatibility for [Ex Deorum](https://www.curseforge.com/minecraft/mc-mods/ex-deorum).

Note: The ore chunk module is automatically generated.

If customization is required, materials or labels need to be specified in the JAOPCA configuration for automatic generation.
